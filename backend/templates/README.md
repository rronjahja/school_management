# Shablloni Word i regjistrimit

Vendosni këtu skedarin tuaj Word me emrin **`regjistrimi.docx`**.

Brenda dokumentit, ku dëshironi të shfaqen të dhënat e studentit,
shkruani këto etiketa (me kllapa gjarpërore):

| Etiketa                 | Vlera                          |
|-------------------------|--------------------------------|
| `{emri}`                | Emri                           |
| `{mbiemri}`             | Mbiemri                        |
| `{datelindja}`          | Datëlindja (DD.MM.YYYY)        |
| `{qyteti}`              | Qyteti                         |
| `{adresa}`              | Adresa                         |
| `{emri_nenes}`          | Emri i nënës                   |
| `{emri_babait}`         | Emri i babait                  |
| `{telefoni}`            | Numri i telefonit              |
| `{drejtimi}`            | Drejtimi i studimit            |
| `{gjenerata}`           | Gjenerata (p.sh. 2025/2026)    |
| `{klasa}`               | Klasa                          |
| `{data_regjistrimit}`   | Data e regjistrimit            |
| `{kuota_vjetore}`       | Kuota vjetore                  |
| `{kuota_neto}`          | Kuota pas zbritjes             |
| `{data_sotme}`          | Data e sotme                   |

Shembull në dokument:

> Studenti **{emri} {mbiemri}**, i lindur më {datelindja} në {qyteti},
> regjistrohet në drejtimin **{drejtimi}** për gjeneratën {gjenerata}.

Pas kësaj, butoni "Gjenero dokumentin" te faqja e studentit
do ta shkarkojë dokumentin e plotësuar automatikisht.
